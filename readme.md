# 🎬 Netflix Titles Analytics Dashboard

An interactive data analytics dashboard built using Python and Streamlit to explore and analyze Netflix Movies and TV Shows.

## 📌 Project Overview

The Netflix Titles Analytics Dashboard helps users explore Netflix content through interactive filters and visualizations. It provides an easy way to understand the distribution of movies and TV shows based on different attributes such as content type, release year, and country.

## ✨ Features

- Interactive dashboard built with Streamlit.
- Filter content by Movies and TV Shows.
- Select a specific release year range.
- Explore Netflix titles through data visualization.
- Analyze Netflix content using Python data analysis libraries.
- Handle missing country values in the dataset.

## 🛠️ Technologies Used

- **Python** – Main programming language.
- **Streamlit** – To build the interactive dashboard.
- **Pandas** – For data cleaning and manipulation.
- **Matplotlib** – For creating visualizations.
- **Seaborn** – For statistical data visualization.

## ⚙️ Installation and Setup

Follow these steps to run the project on your computer.

**1. Clone the repository**

```bash
git clone https://github.com/YOUR_USERNAME/Netflix-Titles-Dashboard.git
```

**2. Open the project folder**

```bash
cd Netflix-Titles-Dashboard
```

**3. Install the required libraries**

```bash
pip install -r requirements.txt
```

**4. Run the dashboard**

```bash
streamlit run app.py
```

The dashboard will open in your web browser.

## 📊 Dataset

The project uses the `netflix_titles.csv` dataset, which contains information about Netflix Movies and TV Shows.

## 🎯 Objective

The main objective of this project is to understand data analysis and visualization concepts by working with a real-world dataset and creating an interactive dashboard.
